# Security policy

Version 0.1.x is the currently maintained series. Review the README's input and
privacy limits before using this tool with sensitive data.

Do not post sensitive files or exploit details in a public issue. Use GitHub's
**Report a vulnerability** button in the repository Security tab if private
reporting is available. Otherwise open an issue titled **Request a private
security contact**, describing only the affected version and asking for a private
channel; wait for that channel before sharing details. No response SLA is promised.

Useful private reports include the version, OS/runtime, a synthetic reproduction,
expected behavior and observed behavior. Do not send live credentials or private
captures. This project has no telemetry or network functionality.
